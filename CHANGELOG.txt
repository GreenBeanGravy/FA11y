8/19/2026 #1:
- Fixed social features reporting as enabled at startup while the friends list remained unavailable until manually logging in. Startup now publishes the authenticated social manager and discovery API to the shared application state used by social keybinds.

8/7/2026 #1:
- Added a Boss Spawns POI category: fixed bosses (currently Harley Quinn, Catwoman, and Poison Ivy) are navigated to directly by name, and rift-spawned bosses appear as "Closest Boss Rift Spawn" with the usual closest-unvisited tracking. Boss types no longer appear in the generic Game Object category.
- Added a Main Vaults POI category with the main map's 10 underground keycard vaults, plus a "Closest Vault" entry that always picks the nearest vault by distance. Vaults are never marked as visited, so you can navigate back to the same vault to find the exit portapotty after looting.
- Regenerated the main map's game objects from current fortnite.gg data. This adds all boss spawn points, a new Rare Chests object type, and updates the chest, ammo box, fishing hole, and fishing rod locations.

8/3/2026 #1:
- Added the Reload Springfield map from the Simpsons collab: full object navigation with 1,825 game objects (chests, ammo boxes, bushes, campfires, and ice machines) plus all 14 named POIs, from Springfield Town Square to the Nuclear Power Plant.
- FA11y now downloads a list of currently-available maps at startup and hides maps that have rotated out of the game (currently main, OG, Elite Stronghold, Slurp Rush, Springfield, and Blitz Starfall). When the list changes, FA11y announces that a new map list is available and that restarting will pull it - map updates no longer require a FA11y release.
- Fixed the Reload map rotation announcer breaking when fortnite.gg changes their page layout, and added the Springfield arena to it. The announcer now ships with a default keybind: Left Alt + Left Shift + R.
- The locker now pre-marks your favorited cosmetics with a star when it opens, matching your real in-game favorites, instead of only remembering favorites toggled during the current session.
- If the configuration menu fails to open, FA11y now speaks the actual error and writes the full details to the log file.

6/17/2026 #1:
- Added a damage reader (off by default). When enabled, FA11y reads Fortnite's hit-damage numbers near the center of the screen and announces each engagement's total damage once the number stops counting up. Only runs during active gameplay, not in menus, the inventory, the map, or the lobby.
- Added the Speak Last Damage keybind (Left Alt + D) to repeat the most recent damage total.
- The damage reader's text recognition runs on your NVIDIA GPU if you have one (chosen during install), otherwise on the CPU.
